Guide & Troubleshooting

Local CORS Error

Ollama などのローカルAPI呼び出しで接続エラーが発生する場合、CORS設定（例: OLLAMA_ORIGINS="*" ollama serve）を確認してください。

Connection Error Detected

外部LLM APIへの接続に失敗しました。CORS（Cross-Origin Resource Sharing）制限、またはサーバーが起動していないことが原因と考えられます。

Ollama CORS Command (macOS / Linux):
OLLAMA_ORIGINS="*" ollama serve
Windows (CMD):
set OLLAMA_ORIGINS=*
ollama serve

サーバーを上記の環境変数を追加して再起動し、ポート番号（デフォルト: 11434）が正しいことを確認して再試行してください。
